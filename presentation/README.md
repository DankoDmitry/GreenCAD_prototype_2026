# Презентация

> Статус: презентация готовится и будет опубликована на этой странице без
> изменения её адреса.

Здесь появятся презентация решения в формате PPTX и её PDF-версия.

В презентации будут показаны:

- проблема и ценность решения для города;
- архитектура и основной алгоритм;
- организация исходных и результирующих слоёв DXF;
- пример интерпретации решения со ссылкой на нормативный источник;
- пример обработки тестового участка;
- способ запуска прототипа;
- ограничения и направления развития.
