# Презентация

## Основная презентация

[Скачать презентацию GreenCAD Desktop в формате PPTX](./GreenCAD_Desktop_LCT_2026.pptx)

В презентации показаны:

- назначение GreenCAD Desktop и состав входных данных;
- рабочий процесс от типизированного DXF до результата;
- фактический результат на полном коридоре 3-й Парковой улицы;
- ручной перенос, копирование, удаление и изменение посадок;
- повторная проверка скорректированного проекта;
- экспорт результата обратно в DXF и открытие в AutoCAD;
- текущие возможности и честно обозначенные границы MVP.

Все численные показатели на слайдах взяты из интерфейса GreenCAD 0.6.1 и
паспорта экспорта тестового проекта. Нормативные расстояния в презентации не
заявляются без подтверждённого источника и версии правила.
