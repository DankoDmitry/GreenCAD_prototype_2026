# Обновление GreenCAD Desktop 0.1 → 0.2

Основа: опубликованный коммит `caa80d562e101387a02220f00a86f2327b01a07e`
репозитория `DankoDmitry/greencad_desktop_v1`.

Обновление подготовлено и проверено локально. Запись через подключение GitHub была отклонена;
этим архивом удалённый репозиторий не изменён. Обычный Pull пока не установит новую функцию.

## Установка в существующую папку

1. Закройте редактор, сохранив рабочий проект. Новые сохранения `.gcp` версии 2 старый редактор
   0.1 не открывает. Для отката оставьте копию исходного `.gcp`.
2. В GitHub Desktop зафиксируйте собственные изменения кода, если они есть, либо сделайте
   копию папки редактора. Если менялись те же файлы, выполните сравнение перед заменой.
3. Откройте `GreenCAD_Desktop_v0.2_update.zip`. Внутри сразу лежат `greencad_editor`, `data`,
   `docs`, `tests` и другие файлы обновления — лишней общей папки нет.
   Скопируйте их в **`D:\ЗагрузкиD\greencad_desktop_v1`**, где находятся `run_editor.py` и
   `START_WINDOWS.bat`. Подтвердите замену файлов, не создавайте вложенную папку редактора.
4. Запустите `setup_windows.bat` ещё раз: требуется Shapely 2.1.2. Интернет нужен только
   для установки зависимостей; рабочий редактор не использует сеть.
5. Запустите `START_WINDOWS.bat`. Появятся «Проверить допуски», «Выбрать проверки…», «Отчёт…».
6. После проверки в GitHub Desktop просмотрите Changes, создайте коммит
   `Add manual planting checks and rule picker` и нажмите Push origin. Так изменения попадут
   в ваш репозиторий. Не добавляйте в коммит свою `.venv` и реальные приватные чертежи.

Архив обновления не содержит `.git`, `.venv`, реальных пользовательских DXF/проектов `.gcp`.
Он также не заменяет начальные демонстрационные DXF. Исключения определены вашим `.gitignore`.

`GreenCAD_Desktop_v0.2.zip` — отдельная полная сборка с примерами для чистой установки.
Её можно распаковать в другую папку; сама она не содержит историю Git.

## Быстрый опыт

Откройте «Демо». Поставьте дерево T1 и введите координаты X=40, Y=31, примените свойства.
Поставьте другое в X=40, Y=34. Нажмите «Проверить допуски».
При начальных правилах первое нарушит **тестовый** отступ 3 м от оси газа,
второе пройдёт выбранные проверки. Эти 3 м не являются нормой из СП.

Переместите дерево: отчёт станет устаревшим. Повторное нажатие пересчитает результат.
В «Выбрать проверки…» отключайте/включайте условия, на вкладке «Параметры» меняйте тестовые
пороги, задавайте A1 и свойства грунта. Нехватка сведений даёт «Недостаточно данных».
Кнопка «Отчёт…» показывает все проверки для всех посадок, не только первое нарушение.

Открытие старого `.gcp` поддерживается; после открытия нужна новая проверка.
Дополнительные сведения: `docs/VALIDATION.md`; результаты тестов: `test_results/VALIDATION_TEST_REPORT.md`.
Windows в среде подготовки этой сборки не запускался.
