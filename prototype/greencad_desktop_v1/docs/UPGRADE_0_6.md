# Обновление GreenCAD Desktop 0.5 → 0.6

Основа: опубликованный коммит `0eaefb18ff0787aacd48d2441b043a38d906422d`.
Архив обновления содержит только изменённые и новые файлы относительно 0.5.
Это не обновление для 0.4: сначала нужна 0.5 либо отдельная полная установка 0.6.

1. Сохраните проект, закройте программу, сделайте резервную копию .gcp.
   Собственные изменения кода зафиксируйте в GitHub Desktop.
2. Скопируйте СОДЕРЖИМОЕ `GreenCAD_Desktop_v0.6_update.zip` в
   `D:\ЗагрузкиD\greencad_desktop_v1`, рядом с `run_editor.py`, с заменой файлов.
   Не создавайте ещё одну вложенную папку. Если редактировали те же файлы, сначала
   сравните изменения, не заменяйте свои правки вслепую.
3. Зависимости прежние; setup запускать повторно не требуется. `.git`, `.venv`,
   пользовательские .gcp и реальные DXF в обновление не включены.
4. Запустите `START_GENERATION_WINDOWS.bat` для примера с анонимными типами
   и шестью ручными посадками. Обычный `START_WINDOWS.bat` тоже сохранён.
5. «Расставить типы…» → green_01 → T1–T4 по 20, шаг 1 м → «Построить вариант».
   Пунктир — предварительное дополнение, исходные 6 точек остаются нетронутыми.
6. «Результат…» → «Применить вариант» → Ctrl+S либо экспорт DXF.
   Ctrl+Z отменяет всю добавленную группу и включённые вместе с ней защитные проверки.
7. Проверьте обновление и отправьте через GitHub Desktop обычный commit/push, например
   `Add deterministic template generation with preview`.

Публикацию/слияние в удалённом репозитории этот архив не выполняет.
Полная ZIP-сборка содержит папку `greencad_desktop_v1` и предназначена для отдельной
установки; не надо одновременно накладывать её и архив обновления.

Форматы: .gcp v4, метаданные шаблонов DXF v2 — не изменены относительно 0.5.
Новые записи происхождения генерации хранятся как обычные дополнительные свойства.
Справочники, исходные Excel/JSON и TEST-пороги не изменены. Генерация не является
доказанным оптимумом, автоматическим подбором вида или полной нормативной экспертизой.

См. `docs/GENERATION.md` и `test_results/GENERATION_TESTS.md`.
