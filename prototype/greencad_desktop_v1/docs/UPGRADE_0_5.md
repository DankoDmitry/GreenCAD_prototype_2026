# Обновление 0.4 → 0.5: расчётные шаблоны

1. Сохраните проект и закройте редактор. Сделайте копию собственных `.gcp`.
2. При локальных изменениях кода сначала зафиксируйте их в GitHub Desktop или сохраните
   копию папки. Не перезаписывайте изменённые вами файлы вслепую.
3. Содержимое `GreenCAD_Desktop_v0.5_update.zip` скопируйте прямо в
   `D:\ЗагрузкиD\greencad_desktop_v1`, где лежит `run_editor.py`, с заменой файлов.
   В архиве нет `.git`, `.venv` и пользовательских сессий. Вложенную папку не создавайте.
4. Запустите `START_WINDOWS.bat` или новое `START_TEMPLATES_WINDOWS.bat` для готового
   примера. Новых зависимостей нет; повторная установка и удаление `.venv` не нужны.
5. После проверки — коммит `Add calculation templates and plant matching` и Push origin.
   Версия передана архивом, автоматически в GitHub не опубликована.

Полный архив предназначен для новой отдельной папки: не устанавливайте его поверх репозитория
дополнительно к архиву обновления. Не совмещайте архив и получение тех же изменений через Git.

## Совместимость

Старые `.gcp` схем 1–3 открываются. Новые сохранения — схема 4, со справочником и профилями
типов. Редактор 0.4 новую схему не читает; для отката используйте сохранённую копию проекта.
Экспорт DXF с шаблонами содержит нашу версию метаданных 2; её также читает новый редактор.
Внешние CAD-проверки не выполнялись.

Открытый исходный DXF не является сохранением рабочего сценария. Для точного переноса настроек
и снимка базы используйте `.gcp`. Настройки типов применяются кнопкой «Сохранить тип», а
Ctrl+S записывает весь проект на диск. Шаблон можно оставить без выбранного растения.

В примере четыре проектных типа имеют условные радиусы и шесть ручных точек. Проверки без
видов работают; подбор по размерам честно показывает UNKNOWN, поскольку в базе размеров нет.
Указание UNKNOWN не означает сбой и не должно заменяться придуманным размером.

Проверка тестами: `RUN_TESTS_WINDOWS.bat`. При ошибке оставьте текст сообщения и журнал
`logs/editor.log`; не удаляйте проект. Новый интерфейс: «Настроить…» → «Расчётный профиль» /
«Критерии подбора» / «Что нужно проверкам». Подробности — `docs/CALCULATION_TEMPLATES.md`.
