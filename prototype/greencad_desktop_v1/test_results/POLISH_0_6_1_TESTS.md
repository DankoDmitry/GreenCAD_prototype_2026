# GreenCAD Desktop 0.6.1 — проверка патча

Дата: 2026-09-29. База: архив 0.6; текущий прочитанный main GitHub
`32dbce22e39382ee42a8a03d15a7c45d7591817b`.
Git blob SHA изменяемых generation.py, generation_ui.py и ui.py совпадают с базой.

## Итог локального прогона

Команда: `xvfb-run -a python -m unittest discover -s tests -v`.
**282 теста, OK** (263 прежних + 19 новых: 13 вычислительных, 6 интерфейсных).
Время этого прогона 86.774 с. Полный лог приложен в `polish_tests.log`.

Архив обновления распакован поверх чистой 0.6 и повторно испытан: **282 теста, OK,
85.943 с**. Полная сборка распакована; её файлы побайтно совпали с результатом
наложения обновления. Все записи манифеста проверены по SHA-256. Полный отдельный
запуск набора на полной сборке не выполнялся — её код идентичен испытанному обновлению.

Новые тесты проверяют:

- одинаковые входы/seed дают одинаковые позиции, ID и job_id;
- другой seed меняет результат; глобальный RNG и входной проект не изменяются;
- прежние JSON-задания остаются сеточными, новые round-trip сохраняют layout/seed;
- ошибочные номера/режимы не превращаются в случайное значение по умолчанию;
- свободные позиции не выровнены по прежним рядам; фиксированный пример покрывает
  четыре части участка (регрессионный пример, не общая статистическая гарантия);
- квота 100 разрешена; действующие отступы, габариты, отверстия и ручные посадки
  сохранены; независимое вычисление расстояний подтверждает результат;
- отмена не меняет проект, неизвестные условия не становятся разрешением;
- применение одной группой, Undo/Redo, .gcp и DXF сохраняют координаты и seed;
- CLI natural сохраняет параметры варианта и итоговый проверенный отчёт;
- реальные кнопки Tk: режим, смена номера, построение, повторное открытие;
- кнопки применения/отмены видны при уменьшении окна и увеличенном Tk scaling;
- жёлтая полоса отсутствует, предупреждение о TEST-порогах сохранено в выборе правил.

## Сквозной пример и снимки окна

`examples/demo_templates.gcp`, зона green_01, квоты T1:35, T2:20, T3:15, T4:15,
шаг 1 м, layout=natural, seed=7. Получено 85 новых + 6 прежних ручных посадок.
Финальная обязательная проверка: PASS. После применения, записи/чтения .gcp и
экспорта DXF — PASS. Исходные сущности проверены экспортёром повторным чтением.
Локальная генерация примера около 0.28 с; это не обещание скорости на иных файлах.
Снимки получены с работающего Tk-окна, не с изображения-схемы. Для чистого вида
в снимке выключены существующие «Метки посадок», данные при этом не меняются.

`python tools/build_reference.py --check`: пакет пересобран и совпал;
его хеш `046a5e8414f1686fe83c502e87e1ea9908b8a8cf8405d1e7987d0b743d2a6f13`.
Справочники, условия, нормативные профили и зависимости не менялись.

## Среда и границы

Linux x86-64, Python 3.13.5, Tk 8.6, Xvfb, Shapely 2.1.2, ezdxf 1.4.4.
Windows и внешние CAD не запускались. Масштабирование Tk в Linux не является
нативным Windows DPI-тестом. Нормативная корректность исходных тестовых порогов
не заявляется. Случайный отбор не доказывает оптимальность, равномерность,
максимальное число посадок или отсутствие других допустимых решений.
