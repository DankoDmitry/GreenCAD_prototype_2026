# GreenCAD 0.6 — повторная проверка пакетов

Проверены два независимых каталога, полученные распаковкой архивов:
1. Полная сборка GreenCAD_Desktop_v0.6.zip.
2. Исходный GreenCAD_Desktop_v0.5.zip + обновление GreenCAD_Desktop_v0.6_update.zip.

Состав и содержимое всех 107 файлов на момент тестового прогона совпали;
контрольные суммы PACKAGE_MANIFEST.json подтверждены. Позднее добавлены только
этот протокол, логи и обновлённый manifest; исполняемый код не менялся.

- **full**: 263 теста, 131.123 с, OK.
- **update**: 263 теста, 132.756 с, OK.

Командный запуск tools/generate_layout.py из распакованной полной сборки также
прошёл: 6 новых (T1/T2 по 3), 6 исходных сохранены, READY, DXF + GCP + два отчёта.
Код возврата 0. Нативный Windows и внешние CAD не испытывались.

После повторной упаковки снова сверены состав обновления и полной сборки,
manifest и идентичность исполняемых файлов тестовым каталогам. Архивы не содержат
.git, .venv, кэшей, ключей доступа или пользовательских проектов вне examples.
