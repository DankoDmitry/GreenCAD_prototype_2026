# Проверка GreenCAD Desktop 0.2

Дата: 2026-09-29. Исходная версия: GitHub main caa80d562e101387a02220f00a86f2327b01a07e.
Перед изменениями проверены SHA файлов редактора против опубликованного дерева; 32 исходных теста прошли.

Итоговый локальный прогон: **65 тестов, все PASS**, 14.034 с.
Из них 49 проверок ядра и 16 проверок реальных Tk-виджетов/событий.
Полный журнал: `validation_tests.txt`.

Среда: Linux x86-64, Python 3.13.5, Tk 8.6, ezdxf 1.4.4, Shapely 2.1.2,
виртуальный дисплей Xvfb. Windows, Python 3.12 и внешние CAD-приложения здесь не запускались.
CI добавлен для Linux/Python 3.12 и 3.13; его результаты не подменяются этим локальным прогоном.

## Проверены

- выполнение всех выбранных условий для каждой посадки, без остановки после первого нарушения;
- отсутствие изменения посадок/исходных байтов при проверке;
- переход PASS/FAIL на известной границе тестового отступа, неизвестный ID/обработчик;
- продолжение других проверок при ошибке одного обработчика;
- неизвестная геометрия, неподдерживаемые кривые, неверная роль, неклассифицированные объекты;
- отсутствие объекта против подтверждённого отсутствия, противоречивое подтверждение;
- независимость расчёта от экранных примитивов и видимости слоя;
- прямые POLYLINE, миллиметры и большие координаты, отверстие в HATCH;
- взаимный конфликт центров, включая совпадающие и закреплённые посадки;
- A1 как незаполненный/заполненный сценарный параметр и диапазоны проектных типов;
- применение исходного примечания [4] и UNKNOWN для отсутствующих характеристик;
- рекомендация «−» не превращается в обязательный запрет;
- кнопка, настоящие клики по галочкам, параметры, фильтр отчёта, выбор посадки из отчёта;
- устаревание отчёта после изменения модели/настроек, отсутствие ложной зелёной обводки;
- сохранение настроек .gcp v2 и чтение старой v1; отчёт требует нового прогона после открытия;
- экспорт DXF с CURRENT/STALE sidecar и контрольной суммой результата;
- прежние 32 теста редактирования, координат, импорта/экспорта и сохранности исходника.

Отдельно выполнен headless CLI на examples/demo_session.gcp: PASS, 6 посадок.
Просмотрены реальные снимки главного окна, выбора правил и подробного отчёта.

## Не утверждается

- Не выполнена новая правовая экспертиза источников и полный нормативный профиль.
- Не реализованы 69 оставшихся записей реестра, полная CAD-геометрия, авторасстановка.
- Значения 3/1/5/3 м — тестовые проектные пороги, не нормы.
- Не измерялась пригодность настоящих растений/объектов и производительность на предельных DXF.
