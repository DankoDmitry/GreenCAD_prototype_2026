Дата: 29.09.2026. База: удалённый main `e3ddc2ad6a355895eb4067179da155d36188bd94`
и локальная поставка 0.4; выбранные исходные файлы сверены с Git blob SHA репозитория.
Публикации коммита/PR этой версии в текущем подключении не выполнялось.

Linux x86-64; Python 3.13.5; Tcl/Tk 8.6.16; ezdxf 1.4.4; Shapely 2.1.2;

xvfb-run -a python -m unittest discover -s tests -v

До изменений запущена база: 144 теста прошли. В процессе разработки был обнаружен
и исправлен конфликт ожидаемой версии сохранения, затем выполнен полный повторный прогон.
Ни один провал теста не скрыт переводом в skip/expectedFailure.

## Что проверяют новые тесты

- Условие профиля без конкретного вида, отсутствие обязательного входа → UNKNOWN.
- Необязательный пустой фильтр игнорируется; заданный фильтр при неизвестном значении → UNKNOWN.
- Преобразование R кроны в D=2R для каталога; размер символа не используется.
- Резерв в зоне, исключённые площади, отверстия через прежние геометрические проверки.
- Симметричный минимум пары: общий минимум, оба минимума типов и сумма резервов.
- Требования реального растения не маскируются шаблоном; неизвестное не заполняется шаблоном.
- Сохранение источников V02205, XLSX-ячейки и статуса каждого отдельно проверенного компонента.
- Прямые, интервальные, булевы и категориальные критерии; частичное пересечение не выдаётся за включение.
- Текст фильтра не исполняется; неверные ID, операции, контекст и типы отклоняются.
- Типы копируются/удаляются с Undo; используемый и последний тип защищены от удаления.
- Данные каталога не меняются при настройке типов; новых цветов и размеров не создаётся.
- GCP v4, чтение GCP v3 с исходным снимком; экспорт и повторное чтение DXF с полными профилями.
- Полная проверка и карта используют одинаковый профиль; явный template_only не проверяет назначенный вид.
- Выбор только PLAN-проверок не превращается в зелёную статическую карту.
- Смена профиля обесценивает прежние результаты, пустой набор правил не даёт PASS.
- Настоящее нажатие «Сохранить тип», повторное открытие, поиск/выбор кандидата и чтение источника.
- UNKNOWN требует явного подтверждения черновика, FAIL не назначается из списка.
- Массовая подстановка сохраняет индивидуальные overrides до явного сброса и планирует повторную проверку.
- Изменение/удаление критериев; неверные значения не применяются частично.
- Нижние кнопки доступны при 800×550 и увеличенном Tk scaling.

## Контрольный пример

`python tools/make_template_example.py` создаёт четыре анонимных типа и шесть ручных
точек в `examples/demo_templates.gcp`. Все шесть проходят выбранные ТЕСТОВЫЕ условия.

```
python tools/check_plan.py examples/demo_templates.gcp --output checks_templates.json
```

Результат PASS, counts={PASS:6}. Расстановка не вычислялась: позиции явно перечислены
в создателе примера, генератор отсутствует.

Карта T1, шаг 2 м, template_only: 1 064 центра; 864 PASS, 200 FAIL;
PLAN-правило R.spacing явно исключено.

Подбор T1 с R=1,5 м: 152 UNKNOWN и 177 FAIL по базе из 329 строк. Ноль подтверждённых
кандидатов объясняется в том числе отсутствием численных размеров в исходном справочнике;
это не ошибка или основание подставить выдуманные значения.
