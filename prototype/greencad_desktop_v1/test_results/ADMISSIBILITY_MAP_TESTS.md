# Проверка карты допустимости 0.3

Дата: 29.09.2026. База: main 8f5411d9f8df0916cd7253583d43cc7356a9873f
(с исправлением «Готово» из PR #1). Полные исходники редактора сопоставлены с
Git blob SHA опубликованной базовой версии перед изменением.

Локальная среда: Linux x86-64, Python 3.13.5, Tk 8.6.16, Xvfb.
Команда: `xvfb-run -a python -m unittest discover -s tests -v`.
**108 тестов прошли**: 75 прежних + 22 новых вычислительных + 11 новых GUI.
Это реальные запуски, не список запланированных сценариев.

Проверены:
- совпадение результатов каждой клетки с validate_plan при тех же статических правилах;
- отсутствие добавления/перемещения посадок, изменения истории и отчёта плана;
- точный щелчок и два разных ответа внутри одной крупной визуальной клетки;
- граничное сравнение >= без скрытого допуска;
- UNKNOWN при незаданном A1/растении/газовой сети, явное подтверждение отсутствия;
- тип/выбор растения/условия грунта из имеющегося каталога;
- FAIL вместе с UNKNOWN; ERROR; пустой набор; рекомендации отдельно;
- новый оператор, неподключённый оператор, неизвестный ID и scope;
- исключение PLAN-условий и отсутствие фиктивного PASS при выборе только PLAN;
- отверстия, раздельные зоны, ни одного центра внутри узкой области;
- миллиметры и сдвиг системы координат;
- лимит ячеек, неконечные/неположительные значения, частичная последняя клетка;
- отмена до запуска и во время вычисления, без публикации частичной карты;
- реальные щелчки Tk по кнопкам и карте, переключение отдельных слоёв;
- устаревание/скрытие слоя, запрет старого объяснения и восстановление через Undo;
- независимость карты от позиций новых посадок, видимости исходных слоёв и масштаба;
- исчезновение слоя после открытия другого/повторно загруженного проекта;
- JSON-экспорт без изменения .gcp/DXF;
- доступность нижних кнопок настроек на малом окне и Tk scaling=2.0.

Снимки фактического окна: карта на демонстрационном участке, отдельный слой газа,
настройки карты. Нативная Windows и внешние CAD-приложения не запускались.

Дополнительный измерительный прогон: demo_block, шаг 0.5 м, 17 024 центра,
15 200 PASS / 1 824 FAIL при начальных трёх TEST-условиях. Построение через GUI
около 1.45 с в этой среде (включая ожидание цикла событий). Слой газа отрисован
112 горизонтальными сериями, не 17 тысячами отдельных интерактивных объектов.
Это один синтетический замер, не гарантия производительности на иных файлах.

CLI также выполнен: `python tools/map_admissibility.py examples/demo_block.dxf
--step 1 --output .../demo_map.json`; 4 256 клеток, 3 800 PASS / 456 FAIL.
Красные клетки не являются ошибкой построения карты.

Выдаваемые ZIP проверены отдельно: полная сборка распакована в новую папку,
архив обновления наложен на копию базы 8f5411d. В обоих случаях повторно прошли
все 108 тестов (23.04 с и 23.14 с соответственно). После этого изменялись только
настоящая запись протокола и контрольный манифест; программные файлы сохранены.
