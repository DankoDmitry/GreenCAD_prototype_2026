# Прототип и способ запуска

> Статус: прототип находится в разработке. Инструкция и демонстрационные файлы
> будут добавлены на эту страницу без изменения её адреса.

Эта страница будет содержать воспроизводимый способ проверки прототипа:

- требования к среде запуска;
- команды сборки и запуска Docker-контейнера под Linux;
- пример входного DXF и необходимых параметров;
- пример выходного DXF;
- пример файла интерпретации результата;
- ожидаемый результат и порядок его проверки.

Графический интерфейс или публично развёрнутый сайт не являются обязательным
условием запуска: основной проверяемый сценарий будет доступен локально по
инструкции.
