# GreenCAD Prototype 2026

Публичный репозиторий решения команды **«Не работаем с утками»** для задачи

учётом расположения подземных коммуникаций и городской среды».

> Статус: материалы решения готовятся. Содержимое будет дополняться по тем же
> постоянным ссылкам; переименование репозитория и разделов не планируется.
