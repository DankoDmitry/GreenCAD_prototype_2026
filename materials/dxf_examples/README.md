# Типизированные DXF для проверки GreenCAD

Используйте файлы из этой папки, а не предыдущую папку `GreenCAD_DXF_samples`.

В каждой CAD-сущности уже записана внутренняя XDATA-метка `GREENCAD_EDIT_V1`: ID, `type_id`, геометрическая роль и происхождение. Отдельный JSON-маппинг для импорта не нужен.

## Файлы

| Файл | Назначение | Объектов |
|---|---|---:|
| `01_3ya_Parkovaya_typed_small_180m.dxf` | Быстрая первая проверка на фрагменте около 180 м | 1 104 |
| `02_3ya_Parkovaya_typed_full_corridor.dxf` | Нагрузочная проверка на полном подготовленном коридоре | 17 026 |
| `03_Kulikovskaya_typed_partial.dxf` | Компактный частичный фрагмент Куликовской улицы | 511 |

Для двух вариантов 3-й Парковой рядом лежат результаты работы настольного прототипа:

| Результат | Расставлено объектов | Сопровождение |
|---|---:|---|
| `01_3ya_Parkovaya_typed_small_180m_edited.dxf` | 267 | `.checks.json`, `.export.json` |
| `02_3ya_Parkovaya_typed_full_corridor_edited.dxf` | 400 | `.checks.json`, `.export.json` |

Эти файлы демонстрируют сохранение исходных слоёв, координат и метаданных GreenCAD. В паспортах честно указано `normative_validation: NOT_IMPLEMENTED`, поэтому они не являются готовым нормативно проверенным проектом.

Логика слоёв:

- `GC_SITE_BOUNDARY` — граница работ, `context.project_domain`;
- `GC_TEST_GREEN_ZONE` — техническая тестовая область, `context.green_zone`;
- `GC_BUILDING` — замкнутые контуры зданий, `base.building`;
- `GC_CURB_EDGE` — бортовой камень / граница проезжей части, `traffic.curb`;
- `GC_GAS_AXIS`, `GC_WATER_AXIS`, `GC_SEWER_AXIS`, `GC_HEAT_AXIS`, `GC_POWER_AXIS` — оси сетей;
- `GC_SIDEWALK`, `GC_SIDEWALK_EDGE` — контуры и края тротуара;
- `GC_DRAINAGE_TRAY` — контуры и оси водоотводных лотков, `net.tray`.

## Как проверить

1. Откройте в GreenCAD снача `01_3ya_Parkovaya_typed_small_180m.dxf`.
2. Нажмите «Вписать», если чертёж не оказался в центре.
3. Выберите границу, здание и любую сеть: типы должны отображаться сразу, без ручного сопоставления слоёв.
4. Для нагрузочной проверки откройте второй файл. Куликовская подходит для дополнительной проверки замкнутых контуров и линейных объектов.

## Важные ограничения

- `GC_TEST_GREEN_ZONE` — это точная копия границы работ, сделанная только для проверки интерфейса и генератора. Это **не** подтверждённая зелёная или пригодная для посадок зона.
- В файлах нет нормативных расстояний и нет принятых посадок.
- Данные 3-й Парковой взяты из реального подготовленного конкурсного CAD, но их текущая актуальность отдельно не подтверждена.
- Куликовская — частичный диагностический фрагмент: в исходной сборке были встроены 45 из 47 внешних ссылок. Не хватало `АСУ_ОДС_Куликовская` и `р7989_Куликовская ул._проект`. Семантика выбрана по явным именам проектных слоёв и остаётся диагностической, а не профессионально подтверждённой.

## Проверка формата

Все три файла открыты штатным загрузчиком `greencad_desktop_v1`:

- единицы — 1 метр на единицу DXF;
- ошибок и предупреждений импорта — 0;
- нетипизированных объектов — 0;
- все ID объектов уникальны.
