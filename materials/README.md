# Дополнительные материалы

В этом разделе хранятся:

1. **предыдущая исследовательская версия GreenCAD** — вспомогательный CAD-конвейер для разбора ZIP-пакетов и подготовки DXF;
2. **типизированные DXF-примеры** для проверки актуального настольного прототипа.

## Предыдущая версия: ZIP/DWG → подготовленный DXF

Эта версия не является основным сдаваемым прототипом. Её главная задача — не расстановка деревьев, а подготовка сложных исходных CAD-материалов к дальнейшей работе.

Конвейер умеет:

- безопасно принимать ZIP-пакет проекта;
- строить инвентарь DWG, DXF, вложенных архивов и сопроводительных файлов;
- показывать кандидатов на основной DWG без молчаливого автовыбора;
- собирать host drawing и найденные XREF в пакет для CAD-препроцессинга;
- при наличии LibreDWG экспериментально конвертировать DWG разных версий в DXF R2010;
- пытаться однозначно разрешить и встроить прямые XREF;
- выпускать отдельный `cad_candidate.flattened.r2010.dxf`, инвентарь слоёв и отчёты о полноте;
- явно сохранять статусы `WARNING` и `partial`, если XREF не найдены или эталонный DXF не подтверждает качество конверсии.

Модули расстановки и проверки посадок в исходном коде есть, но в рамках этого дополнительного материала они рассматриваются как вторичный и демонстрационный сценарий. Для расстановки объектов предназначен актуальный настольный прототип GreenCAD.

### Быстрый запуск

Требуются Python 3.12 и Linux. После распаковки `GreenCAD_previous_source.zip`:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[web]"
python tools/run_web.py
```

Затем открыть `http://127.0.0.1:8000`, создать проект и загрузить ZIP-пакет. Интерфейс покажет состав архива, CAD-кандидатов и следующий допустимый шаг.

Для экспериментального DWG→DXF нужен `dwg2dxf` из LibreDWG. Путь можно передать так:

```bash
export GREENCAD_DWG2DXF=/usr/bin/dwg2dxf
python tools/run_web.py
```

Если конвертер не установлен, GreenCAD всё равно проанализирует пакет и соберёт `cad_handoff.zip` для внешнего CAD-экспорта.

### Границы применимости

- Произвольный DWG не объявляется корректно преобразованным без проверок и, по возможности, эталонного DXF.
- Ненайденные или неоднозначные XREF не подставляются автоматически.
- Имя слоя даёт только подсказку, а не профессионально подтверждённую семантику.
- Конвейер не подтверждает актуальность редакции исходного проекта.

## DXF-примеры

В папке [dxf_examples](dxf_examples/) лежат три самодостаточных типизированных DXF:

- малый фрагмент 3-й Парковой;
- полный коридор 3-й Парковой;
- частичный диагностический фрагмент Куликовской.

Для 3-й Парковой также сохранены экспортированные файлы `_edited.dxf` с расставленными в настольном прототипе объектами, отчёты `.checks.json` и паспорта `.export.json`. Эти экспорты подходят для демонстрации интерфейса и формата результата, но не являются нормативно проверенным проектом.
