# Документация

> Статус: финальная документация готовится и будет опубликована на этой
> странице без изменения её адреса.

Здесь появятся PDF-версия документации и, при необходимости, её материалы в
Markdown.

Документация будет включать:

- назначение, границы MVP и известные ограничения;
- архитектуру, компоненты, поток данных и схему развёртывания;
- описание алгоритма формирования посадок и работы со слоями DXF;
- механизм интерпретируемости и привязку решений к НПА и конкретным пунктам;
- схему процесса от входного DXF до выходного результата;
- используемые методы, библиотеки и источники;
- пошаговую инструкцию по сборке, запуску и проверке в Docker под Linux;
- описание доступных способов взаимодействия с решением;
- Swagger / OpenAPI, если в финальной версии используется HTTP API.
